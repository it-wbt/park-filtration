PARK chatbot: Google Sheet setup

1. Create or choose the Google Sheet that will receive enquiries.
2. Open Extensions > Apps Script. Paste Code.gs into the script project.
3. In Project Settings > Script Properties, add:
   SHEET_ID is optional; Code.gs defaults to the supplied PARK lead Sheet.
   To use a different spreadsheet later, set SHEET_ID to the ID between /d/ and /edit.
   ALLOWED_ORIGINS: your exact website origin(s), separated by commas.
   For local testing include http://localhost:3000. For production include
   https://your-domain.example and the www origin if it is used.
4. Deploy > New deployment > Web app. Execute as: Me. Access: Anyone.
   Authorize spreadsheet access with the Sheet owner's account.
5. Copy the deployed /exec URL. Set it in the website environment:
   NEXT_PUBLIC_GOOGLE_ENQUIRY_URL=https://script.google.com/macros/s/DEPLOYMENT_ID/exec
   For local development, put this line in a new `.env.local` file in the
   website project root. `.env.example` is only a template and is not loaded.
6. Restart the local server, or rebuild and redeploy the website. Production
   deployments need NEXT_PUBLIC_GOOGLE_ENQUIRY_URL set in their build environment.
7. Chat messages are logged in the Chat Logs tab (session, time, site, speaker,
   and message). Completed quote requests are saved in Enquiries with Query and
   Requirement columns. The chatbot saves to the Sheet only; it sends no email.

The public URL is safe to include in the frontend; account credentials stay in
Apps Script. WhatsApp remains a separate button. Retrying updates the existing
lead rather than adding another one. Update the deployment version when changing
Code.gs. Google account quotas apply to spreadsheet operations.
